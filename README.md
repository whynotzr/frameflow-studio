## ✨ Fonctionnalités
* **Éditeur de Design Tokens** réactif géré via **Zustand**.
* **Audit d'accessibilité WCAG 2.1** en temps réel (calcul de luminance relative et grades `AA` / `AAA`).
* **Export multi-formats** instantané : Variables CSS (`:root`), configuration **Tailwind CSS** et **Figma Tokens JSON**.
* **Qualité industrielle** : Tests unitaires `Vitest`, build `Vite` optimisé, `Dockerfile` Nginx et CI GitHub Actions.

## 🚀 Développement local
```bash
git clone https://github.com/whynotzr/frameflow-studio.git
cd frameflow-studio
npm install
npm run dev
```
